# Bienvenue sur le site officiel d'Amikone

Bienvenue sur le nouveau site web officiel d'**Amikone**. Après des mois d'expérimentation sur Flutter, nous lançons ce petit espace pour mieux vous présenter le projet, partager notre vision et garder un fil d'actualité.

## Amikone, c'est quoi ?

**Amikone** est le client mobile (iOS & Android) du projet **AmikOne**. L'objectif est simple : proposer une alternative aux géants des applications de rencontre, tout en privilégiant la **transparence** plutôt que l'opacité algorithmique.

Quelques piliers guident ce projet :

- **Open source.** L'intégralité du code est lisible, auditable et modifiable.
- **Décentralisé & multi-instances.** Choisissez votre propre instance Supabase, ou utilisez celle de la communauté. Vous décidez où sont vos données.
- **Éthique avant viralité.** L'expérience est pensée pour être saine, sans dark pattern et sans monétisation à tout prix.
- **Soutenu par la communauté.** Les idées, retours et contributions font avancer Amikone bien plus que tout autre chose.
- **Respect de la vie privée.** Le minimum nécessaire. Vous restez maître de ce que vous partagez.

## Un labo, pas une copie

Comme le précise le README officiel, Amikone est avant tout un **laboratoire d'idées**. Ce n'est pas une template à reproduire, mais un terrain d'expérimentation pour imaginer une autre manière de faire la rencontre : plus transparente, plus respectueuse, plus libre.
